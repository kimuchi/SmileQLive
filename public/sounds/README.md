# 効果音ファイル

会場投影画面 (`/present/[roomId]`) だけがここの音源を再生します。
参加者のスマートフォンからは一切再生しません（参加者画面は音声モジュールを読み込みません）。

## 必要な 6 ファイル

| 名前 | 鳴らすタイミング | 目安の長さ |
|---|---|---|
| `question-start` | 回答受付を開始したとき | 0.6〜1.5 秒 |
| `tick` | 残り 5・4・3・2・1 秒（1 秒ごとに 1 回） | 0.1〜0.3 秒 |
| `answer-lock` | 回答を締め切ったとき | 0.5〜1.2 秒 |
| `answer-reveal` | 正解を発表したとき | 1.0〜2.0 秒 |
| `ranking` | ランキングを表示したとき | 1.0〜2.5 秒 |
| `finish` | クイズを終了したとき | 1.5〜3.0 秒 |

## 差し替え方

再生するファイル名は `manifest.json` に書かれた値だけです。
拡張子はここで自由に変えられます（`.mp3` / `.wav` / `.ogg` など、投影に使うブラウザが再生できる形式）。

```json
{
  "question-start": "question-start.mp3",
  "tick": "tick.mp3",
  "answer-lock": "answer-lock.mp3",
  "answer-reveal": "answer-reveal.mp3",
  "ranking": "ranking.mp3",
  "finish": "finish.mp3"
}
```

- ファイル名は `public/sounds/` からの相対で書きます。外部ホストの URL は読み込みません（同一オリジンのみ）。
- ファイルが無い場合はブラウザのコンソールに警告が出るだけで、投影は止まりません。
- 音源を入れ替えたら、出典とライセンスを必ず [LICENSE.md](./LICENSE.md) へ記録してください。

## 推奨仕様

- サンプリング周波数: 44.1kHz
- チャンネル: モノラルで十分（ステレオでも可）
- 長さ: 上表のとおり短尺。`tick` は特に短く、次の秒に重ならないこと
- 音量: -14 LUFS 目安。6 ファイルの体感音量をそろえる（`tick` はやや控えめ）
- 冒頭の無音を詰める（合図として遅れて聞こえないようにする）
- 末尾は自然にフェードアウトさせ、ブツッというノイズを残さない
- 1 ファイル 200KB 以内が目安（会場 Wi-Fi での先読みを軽くするため）

## 動作確認用のプレースホルダ

権利関係を気にせず動作確認するための WAV を、その場で生成できます（外部依存なし・自家生成）。

```bash
node scripts/generate-placeholder-sounds.mjs
```

- `public/sounds/` に 6 つの `.wav` を作り、`manifest.json` を `.wav` へ書き換えます。
- 生成物はあくまで確認用です。本番では実際の音源へ差し替えてください。
- 既存ファイルを上書きしたくない場合は `--keep-existing` を付けます。

## 本番前の確認

1. 投影に使う実機のブラウザで `/present/[roomId]` を開く
2. 「投影を開始して全画面へ」を押す（この操作より前には音を鳴らしません）
3. 会場スピーカーの音量で 6 種類すべてを聞き、音量差がないか確認する
4. 会場の暗騒音の中で `tick` が聞き取れるか確認する
