# 効果音

投影画面（`/present/*`）だけで鳴らします。参加者の端末からは一切音を出しません。

## そのまま鳴ります（同梱音）

`public/sounds/default/*.wav` に自家生成の効果音が入っています。
正弦波を組み合わせて作ったもので第三者の権利を含まないため、リポジトリへ同梱してあり、
デプロイした時点で何も用意せずに鳴ります。

作り直す場合:

```bash
npm run sounds:generate
```

## 別の音源へ差し替える

`public/sounds/` **直下**へ置いた音源が同梱音より優先されます。

```bash
npm run sounds:install                       # 何をどこから入手するかを表示
npm run sounds:install -- --from ~/Downloads # ダウンロード済みのフォルダから取り込む
```

**外部の音源はこのリポジトリに含まれません。** 効果音ラボの規約が素材の再配布と直リンクを
禁じているため、ダウンロードは利用者がブラウザで行い、スクリプトは取り込みと出典の記録だけを行います。
`public/sounds/*.mp3` `*.wav` `*.ogg`（直下のみ）は `.gitignore` 済みです。

取り込むと `manifest.json` と `LICENSE.md` が自動更新されます。
同梱音へ戻したいときは `npm run sounds:generate` を実行してください。

## 鳴らないときの確かめ方

```bash
npm run sounds:check                            # 手元のファイルを確かめる
npm run sounds:check -- --url https://<公開URL> # 公開中のサイトを確かめる
```

投影画面の「投影準備」にも、読み込めた件数と足りない音が表示されます。
「音声テスト」を押すと、鳴らせたかどうかが文字で返ります。

`public/sounds/` 直下へ置いた音源は Git に入らないため、
**取り込んだ端末からデプロイしないと公開先では鳴りません。**

## 手作業で差し替える

1. `public/sounds/` へ置く
2. `manifest.json` のファイル名を更新する（`manifest.json` からの相対パス）
3. `LICENSE.md` へ出典・ライセンス・取得日を記録する

---

会場投影画面 (`/present/[roomId]`) だけがここの音源を再生します。
参加者のスマートフォンからは一切再生しません（参加者画面は音声モジュールを読み込みません）。

## 必要な 7 ファイル

| 名前 | 鳴らすタイミング | 目安の長さ |
|---|---|---|
| `question-start` | 回答受付の開始 | 1 秒前後 |
| `tick` | 残り 5〜0 秒（毎秒 1 回） | 0.2 秒以内 |
| `answer-lock` | 回答の締め切り | 1 秒前後 |
| `answer-reveal` | 正解の発表 | 1.5 秒前後 |
| `ranking` | ランキング発表前の「ため」 | 2〜4 秒 |
| `fanfare` | ランキングが出た瞬間 | 2 秒前後 |
| `finish` | クイズの終了 | 2〜3 秒 |

`ranking` が鳴り終わったところで順位を出し、同時に `fanfare` を鳴らします。
順位を出すまでの間は `ranking` の**実際の長さ**に合わせるため、
長い素材にすると、そのぶん長くためます（1.5〜6 秒の範囲に収めます）。

`tick` が長くても、次の秒が来た時点で前の音を止めるので重なりません。
ただし毎秒鳴るので、短い素材のほうが自然です。
