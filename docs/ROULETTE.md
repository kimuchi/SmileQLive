# URL だけで回すルーレット — SmileQ Live

会議の司会決め、席替え、罰ゲーム、景品の当たり外し。
「その場で開いて 1 回まわす」ためのルーレットです。

**ログインもルーム作成も要りません。** `/roulette` を開くだけです。

```
https://<公開URL>/roulette
```

盤面はサーバーに保存しません。**URL が保存先**です。
作った盤面は URL として書き出せるので、貼っておけば来年も同じ盤面が開けます。

> ルームを作って進める**抽選会のルーレット**（[DRAW_MODES.md](./DRAW_MODES.md)）とは別物です。
> あちらはサーバーが引いて記録し、司会画面と投影画面が分かれます。
> こちらはブラウザの中だけで完結し、記録も残りません。

---

## 1. 使い方

### 1.1 1 から作る

`/roulette` を開くと、空の入力欄が出ます。

1. 項目名を入れる（2 つ以上で回せます）
2. 必要なら**重み**を変える（大きいほど扇が広くなり、当たりやすくなります）
3. 「スタート」

「リセット」で回転を最初へ戻し、それまでの結果も消します。

### 1.2 表計算ソフトから入れる

設定 → **貼り付け・CSVで入れる**。

```text
項目,重み
山田 太郎,1
田中 花子,3
佐藤,
```

- 左から「項目名」「重み」の順に読みます（重みを書かなければ 1）
- 1 行目が「項目」「重み」などの見出しなら自動で飛ばします
- 「いまの内容と入れ替える」か「いまの内容に足す」かを選べます

取り込む前に**必ず下見が出ます**。何件入るか、何を飛ばしたかを確かめてから押してください。

> ファイルはサーバーへ送りません。ブラウザの中で読むだけです。
> Excel が書き出した Shift_JIS の CSV も、文字化けを見つけたら自動で読み直します。

### 1.3 盤面を保存する・人に渡す

設定 → **URLをコピー**。

サーバーには何も保存していないので、この URL が保存先になります。
社内の連絡ツールへ貼っておけば、次のときに同じ盤面がそのまま開けます。

## 2. URL の形

```
/roulette?json={"name":["山田","田中"],"ratio":[1,2],"show_characters_value":true,"decel_value":0.008}
```

| 項目                    | 意味                                                |
| ----------------------- | --------------------------------------------------- |
| `name`                  | 扇に並べる項目名（順番どおりに並びます）            |
| `ratio`                 | 重み。`name` と同じ数だけ並べます（足りなければ 1） |
| `show_characters_value` | 扇の中に項目名を書くか                              |
| `decel_value`           | 減速の強さ。大きいほど早く止まります                |

この形は配布されているルーレット
（[exe.tanidaiz.com/roulette.php](https://exe.tanidaiz.com/roulette.php)）と**同じ**です。
向こうで作った URL をそのまま開けますし、こちらで書き出した URL を向こうへ貼っても開けます。
「去年の URL がある」と言われたときに作り直さずに済むよう、意図してそろえてあります。

壊れた URL を開いても白い画面にはなりません。読めなかったことを伝えて、その場で作り直せます。

### 上限

| 何                   | 上限    |
| -------------------- | ------- |
| 項目の数             | 200 件  |
| 項目名の長さ         | 60 文字 |
| 重み                 | 1〜1000 |
| URL の `json` の長さ | 64 KB   |

200 を超えると 1 つの扇が 1.8 度より狭くなり、画面では線にしか見えません。

## 3. 回り方と当たりの決め方

押すと一定の割合で減速し、**ひとりでに止まります**。ストップのボタンはありません。

### 3.1 止まるまでの長さ

「回る長さ（減速）」のつまみで変えられます。設定欄に**およそ何秒で止まるか**が出るので、
会場の空気に合わせてその場で調整してください。

| 減速 (`decel_value`) | 止まるまでの目安 |
| -------------------- | ---------------- |
| 0.002                | 約 19 秒         |
| 0.004                | 約 13 秒         |
| 0.008（既定）        | 約 9 秒          |
| 0.02                 | 約 6 秒          |
| 0.08                 | 約 3 秒          |

単位は「1 フレーム（60 分の 1 秒）あたり何度ぶん速度が落ちるか」です。
配布サイトの `decel_value` をそのまま貼れるように合わせてあります。

### 3.2 どこで止まるか

**先に当たりを決めてから角度を合わせる、という作りにはしていません。**
回した先にあったものが当たりです。回している間、当たりは画面のどこにもありません。

ただし「初速を適当に散らす」やり方もしていません。それだと止まる角度の分布が
初速の散らし方に引きずられ、扇の広さどおりの確率になりません。

実際には、

1. **止まる角度を 0〜360 度から一様に引く**
2. そこへちょうど着く初速を、減速から逆算する

という順で決めています。止まる角度が一様なので、ある扇に止まる確率は
**その扇の広さにきっちり比例します**（＝重みどおりになります）。
1 : 3 の 2 枠なら 25% : 75% です。

> 厳密なくじ引きの用途には向きません。ブラウザの中で決めているので、
> 開発者ツールを開ける人には結果を書き換えられます。
> 記録が要る抽選には[抽選会モード](./DRAW_MODES.md)を使ってください。

### 3.3 当たったものは減りません

同じ項目が何度でも出ます。扇が減ると重みの意味が無くなるためです
（抽選会・ビンゴは引いたものを外しますが、ルーレットは外しません）。

## 4. 効果音

| 名前        | 鳴るところ                     |
| ----------- | ------------------------------ |
| `draw-spin` | 回している間ずっと（繰り返し） |
| `draw-win`  | 止まった瞬間                   |

抽選会のルーレットと同じ音です。差し替えると両方に反映されます。

投影機やノートパソコンのブラウザは、**一度画面を操作するまで音を鳴らしません**。
鳴らない状態のときだけ画面の下に案内が出るので、そこから有効にしてください。
案内が出ていても回すこと自体はできます。

## 5. 効果音の差し替え（ログイン不要）

```
https://<公開URL>/sounds
```

**ログインは要りません。** 会場では投影担当・司会・音響が別の人で、別の端末で画面を開きます。
「音を差し替えたいだけ」なのにログインを求めると、当日その場で直せません。

差し替えた音は**システム全体**（すべてのクイズ・抽選会・ビンゴ・ルーレット・投票）で鳴ります。
デプロイし直す必要はありません。

> ### ⚠ 誰でも差し替えられます
>
> ログインを求めない代わりに、**URL を知っている人は誰でも音を差し替えられます**。
> 社内の催しで使う前提の割り切りです。社外から開ける場所へ置く場合は、
> Cloud Run 側で入口を絞ってください（IAM・IAP・社内ネットワーク限定など）。
> `/sounds` と `/api/sound-settings` の両方を塞ぐ必要があります。
>
> 歯止めとして、同一オリジンからの送信だけ・大きさの上限・
> 実データによる形式判定・回線ごとの回数制限は入れてあります。

素材については [OPERATIONS.md](./OPERATIONS.md) の効果音の節を参照してください
（効果音ラボの規約により、素材はリポジトリへ同梱していません）。

## 6. 投影して使う

「全画面」で投影機いっぱいに出せます。「設定」を閉じると盤面が大きくなります。

スマートフォンでも同じ画面が使えます（画面の幅に合わせて縦に並びます）。
