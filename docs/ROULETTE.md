# URL だけで回すルーレット — SmileQ Live

会議の司会決め、席替え、罰ゲーム、景品の当たり外し。
「その場で開いて 1 回まわす」ためのルーレットです。

**ログインもルーム作成も要りません。** `/roulette` を開くだけです。

```
https://<公開URL>/roulette
```

盤面はサーバーに保存しません。**URL が保存先**です。
作った盤面は URL として書き出せるので、貼っておけば来年も同じ盤面が開けます。

> ルームを作って進める**抽選会のルーレット**（[DRAW_MODES.md](./DRAW_MODES.md)）とは別物です。
> あちらはサーバーが引いて記録し、司会画面と投影画面が分かれます。
> こちらはブラウザの中だけで完結し、記録も残りません。

---

## 1. 使い方

### 1.1 1 から作る

`/roulette` を開くと、空の入力欄が出ます。

1. 項目名を入れる（2 つ以上で回せます）
2. 必要なら**重み**を変える（大きいほど扇が広くなり、当たりやすくなります）
3. 「スタート」で回り出します。**押すまで止まりません。**
4. 「ストップ」で減速して止まります

「リセット」で回転を最初へ戻し、それまでの結果も消します。

### 1.2 表計算ソフトから入れる

設定 → **貼り付け・CSVで入れる**。

```text
項目,重み
山田 太郎,1
田中 花子,3
佐藤,
```

- 左から「項目名」「重み」の順に読みます（重みを書かなければ 1）
- 1 行目が「項目」「重み」などの見出しなら自動で飛ばします
- 「いまの内容と入れ替える」か「いまの内容に足す」かを選べます

取り込む前に**必ず下見が出ます**。何件入るか、何を飛ばしたかを確かめてから押してください。

> ファイルはサーバーへ送りません。ブラウザの中で読むだけです。
> Excel が書き出した Shift_JIS の CSV も、文字化けを見つけたら自動で読み直します。

### 1.3 盤面を保存する・人に渡す

**触った内容は自動で残ります。** 読み込み直しても消えません。

- 項目や設定を変えると、**アドレス欄の URL がその場で書き換わります**。
  この URL が保存先です。読み込み直しても、閉じて開き直しても同じ盤面が出ます。
- URL を控えずに閉じてしまっても、`/roulette` を開けばその端末に残った
  前回の内容が出ます（「前回の内容を出しました」と表示されます）。
- 人から URL を渡されて開いたときは、**渡された URL のほうが優先**です。
  自分の前回の内容で上書きはしません。

人へ渡すときは 設定 → **URLをコピー**。
社内の連絡ツールへ貼っておけば、次のときに同じ盤面がそのまま開けます。

> 残しているのはブラウザの中だけで、サーバーへは送っていません。
> 別の端末で開くときは URL を渡してください。

## 2. URL の形

```
/roulette?json={"name":["山田","田中"],"ratio":[1,2],"show_characters_value":true,"decel_value":0.008}
```

| 項目                    | 意味                                                |
| ----------------------- | --------------------------------------------------- |
| `name`                  | 扇に並べる項目名（順番どおりに並びます）            |
| `ratio`                 | 重み。`name` と同じ数だけ並べます（足りなければ 1） |
| `show_characters_value` | 扇の中に項目名を書くか                              |
| `decel_value`           | 減速の強さ。**配布サイト互換のための項目**（下記）  |
| `speed_value`           | 回っている間の速さ（度/秒）。360 で 1 秒に 1 周     |
| `stop_seconds`          | ストップを押してから止まるまでの秒数                |
| `background_url`        | 投影の背景に敷く画像の URL（`http(s)` のみ）        |

上 4 つは配布されているルーレット
（[exe.tanidaiz.com/roulette.php](https://exe.tanidaiz.com/roulette.php)）と**同じ**です。
向こうで作った URL をそのまま開けますし、こちらで書き出した URL を向こうへ貼っても開けます
（あちらは知らない項目を無視します）。
「去年の URL がある」と言われたときに作り直さずに済むよう、意図してそろえてあります。

`decel_value` はこちらでは直接使いません。

- **書き出すとき** … 速さと止まるまでの秒数から換算して入れます
  （720 度/秒 を 5 秒で止めるなら 0.04）。あちらへ貼っても近い回り方になります。
- **読むとき** … `speed_value` と `stop_seconds` があればそちらを使います。
  無ければ（＝あちらから来た URL なら）`decel_value` を
  「この速さでその減速をかけたら何秒で止まるか」へ読み替えます。

壊れた URL を開いても白い画面にはなりません。読めなかったことを伝えて、その場で作り直せます。

### 上限

| 何                   | 上限    |
| -------------------- | ------- |
| 項目の数             | 200 件  |
| 項目名の長さ         | 60 文字 |
| 重み                 | 1〜1000 |
| URL の `json` の長さ | 64 KB   |

200 を超えると 1 つの扇が 1.8 度より狭くなり、画面では線にしか見えません。

## 3. 回り方と当たりの決め方

**スタートで等速に回り続け、ストップで減速して止まります。**
勝手には止まりません。「そろそろ止めます」の間を司会が作れるようにするためです。

### 3.1 速さと止まるまでの時間

**別々のつまみです。** 速く回して短く止めることも、
ゆっくり回して長く引っぱることもできます。

| つまみ           | 範囲                            | 既定                 |
| ---------------- | ------------------------------- | -------------------- |
| 回る速さ         | 90〜2160 度/秒（0.25〜6 周/秒） | 720 度/秒（2 周/秒） |
| 止まるまでの時間 | 0.5〜30 秒                      | 5 秒                 |

設定欄には「1 秒に何周」「何秒かけて止まります」と出るので、
会場の空気に合わせてその場で調整してください。

### 3.2 どこで止まるか

**先に当たりを決めてから角度を合わせる、という作りにはしていません。**
回した先にあったものが当たりです。回している間、当たりは画面のどこにもありません。

ただし「勢い任せ」にもしていません。それだと止まる角度の分布が
回した長さに引きずられ、扇の広さどおりの確率になりません。

ストップを押した瞬間に、

1. **止まる角度を 0〜360 度から一様に引く**
2. そこへちょうど着くまでの距離を、いまの角度から求める

という順で決めています。止まる角度が一様なので、ある扇に止まる確率は
**その扇の広さにきっちり比例します**（＝重みどおりになります）。
1 : 3 の 2 枠なら 25% : 75% です。

> 厳密なくじ引きの用途には向きません。ブラウザの中で決めているので、
> 開発者ツールを開ける人には結果を書き換えられます。
> 記録が要る抽選には[抽選会モード](./DRAW_MODES.md)を使ってください。

### 3.3 決まったときの見せ方

止まると、当たった名前を**大きく出して**光線・輪・閃光・紙吹雪を添えます。
音も当選音とファンファーレを重ねて鳴らします。
1 音・小さな文字だけだと、会場では「止まった」ようにしか見えないためです。

当たり以外の扇は薄くなるので、どこで止まったのかが遠くからでも分かります。

### 3.4 当たったものは減りません

同じ項目が何度でも出ます。扇が減ると重みの意味が無くなるためです
（抽選会・ビンゴは引いたものを外しますが、ルーレットは外しません）。

## 4. 効果音

| 名前        | 鳴るところ                          |
| ----------- | ----------------------------------- |
| `draw-spin` | 回している間ずっと（繰り返し）      |
| `draw-win`  | 止まった瞬間                        |
| `fanfare`   | 止まった瞬間（`draw-win` と重ねて） |

抽選会のルーレットと同じ音です。差し替えると両方に反映されます。

**「効果音を有効にする」のような操作は要りません。**
ブラウザは画面を一度も操作しないうちは音を鳴らさない決まりですが、
このルーレットは必ずスタートを押してから音が要るので、その 1 押しで解除まで済みます。
そのため案内の帯もテストのボタンも置いていません。

> 効果音の設定を読めないときは、**同梱の音に倒れます**。
> 差し替えた音が鳴らないのと、音が一切鳴らないのとでは会場での痛さが違うためです。

## 5. 効果音の差し替え（ログイン不要）

```
https://<公開URL>/sounds
```

**ログインは要りません。** 会場では投影担当・司会・音響が別の人で、別の端末で画面を開きます。
「音を差し替えたいだけ」なのにログインを求めると、当日その場で直せません。

差し替えた音は**システム全体**（すべてのクイズ・抽選会・ビンゴ・ルーレット・投票）で鳴ります。
デプロイし直す必要はありません。

> ### ⚠ 誰でも差し替えられます
>
> ログインを求めない代わりに、**URL を知っている人は誰でも音を差し替えられます**。
> 社内の催しで使う前提の割り切りです。社外から開ける場所へ置く場合は、
> Cloud Run 側で入口を絞ってください（IAM・IAP・社内ネットワーク限定など）。
> `/sounds` と `/api/sound-settings` の両方を塞ぐ必要があります。
>
> 歯止めとして、同一オリジンからの送信だけ・大きさの上限・
> 実データによる形式判定・回線ごとの回数制限は入れてあります。

素材については [OPERATIONS.md](./OPERATIONS.md) の効果音の節を参照してください
（効果音ラボの規約により、素材はリポジトリへ同梱していません）。

## 6. 投影して使う

**横長の画面では、盤面が画面の高さいっぱいに出ます。** 結果とボタンはその右側です。
「全画面」で投影機いっぱいに広げられます。
「設定」は開いている間も出したままなので、そのまま閉じられます。

スマートフォンなど縦長の画面では、盤面の下に結果とボタンが並びます。

### 6.1 背景画像

設定 → **投影の背景**。入れ方は 2 つあり、性質が違います。

| 入れ方               | どこまで届くか                                                      |
| -------------------- | ------------------------------------------------------------------- |
| 画像の URL を入れる  | 盤面の URL に載ります。**渡した相手の画面にも出ます**               |
| 手元のファイルを選ぶ | **その端末・そのタブだけ。** 読み込み直すと消え、URL にも載りません |

会場で使い回すなら URL を入れてください。社内の共有フォルダやサイトに置いた画像で構いません。

背景はそのままの色で出ます。文字が沈まないよう、字の側に影を付けています。

> `http://` と `https://` で始まる URL しか受け付けません。
> 背景の URL は人から人へ渡るので、それ以外を許すと
> URL を送るだけで相手の画面で好きなことができてしまいます。
