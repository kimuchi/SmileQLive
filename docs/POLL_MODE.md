# 投票モードの進め方 — SmileQ Live

会場の全員がスマートフォンから投票し、その結果を舞台で発表するためのモードです。
出し物コンテスト、いちばん良かった発表を選ぶ場面、社内表彰などで使います。

参加はクイズと同じく**二次元コードの読み取りだけ**です。
アプリのインストールも、コードの入力も要りません。

---

## 1. できること

| 決めること         | 選べる範囲                                                           |
| ------------------ | -------------------------------------------------------------------- |
| 選び方             | 一覧から選ぶ／2段階で選ぶ（区分 → 中身）                             |
| 何位まで選ぶか     | 1位だけ〜5位まで                                                     |
| 順位ごとの点数     | 0〜1000点を順位ごとに自由に（例: 5 / 3 / 1）                         |
| 何位まで発表するか | 1位だけ〜10位まで。**選ぶ順位とは別に決められます**                  |
| 発表前の手直し     | 締め切ったあと、司会が票数を直せます（紙の投票を足す・異常値を外す） |

**1台につき1票**です。同じ端末から入れ直すことはできません。

---

## 2. 準備 — 投票用紙を作る

管理画面 → **投票用紙** → 新規作成。

### 2.1 選び方を決める

- **一覧から選ぶ（flat）** … 選択肢を並べて、そこから選びます。候補が 20 件くらいまでならこちら。
- **2段階で選ぶ（nested）** … まず区分（部署・チームなど）を選び、その中から選びます。
  候補が多いときに、スマートフォンの画面で選びやすくなります。

あとから変えられます。

### 2.2 選択肢を入れる

1 件につき「名前」と「補足」（発表者名など。省略可）を入れます。
2段階のときは、全部の選択肢に区分を割り当ててください。

> **区分に属していない選択肢は保存できません。**
> 参加者が選べない選択肢になり、当日に気づくのでは遅いためです。

並び順は、同点だったときの順番にも使います。

**「区分と選択肢を保存する」を押すまでサーバーへ反映されません。**
名前・点数・発表の設定は自動保存ですが、選択肢の一覧は丸ごと入れ替えるため、
打鍵のたびに送ると入力中の空欄が落ちてしまいます。

### 2.3 何位まで選ぶか・点数

「良かった順に 3 つ」のように選ばせる場合は、順位ごとの点数を決めます。

| 例                        | rankDepth | points    | 意味                              |
| ------------------------- | --------- | --------- | --------------------------------- |
| いちばん良かったものを1つ | 1         | [1]       | 得票数がそのまま点数              |
| 3位まで選ぶ（重み付き）   | 3         | [5, 3, 1] | 1位票=5点 / 2位票=3点 / 3位票=1点 |
| 3位まで選ぶ（同じ重み）   | 3         | [1, 1, 1] | 順位は付けるが重みは付けない      |

0点にすると「選べるが点は入らない」になります。

### 2.4 結果発表の設定

- **何位まで発表するか** … 3 なら 3位 → 2位 → 1位の順に出します。
  選ぶ順位とは別に決められるので、**3位まで選ばせて1位だけ発表する**こともできます。
- **結果の文字の大きさ** … 1920×1080 の投影での px。長い名前は自動で縮みます。
- **投影の背景** … 結果発表の背景に敷く画像。選ばなければ既定の背景です。

## 3. 当日の流れ

### 3.1 ルームを作る

管理画面 → ルーム一覧 → 新規作成 → モード「**投票**」→ 投票用紙を選ぶ。

作成した時点の用紙の内容をルームへ写し取ります。
**あとから用紙を直しても、進行中のルームの中身は変わりません。**

作成すると参加用の二次元コードが出ます。投影画面にも同じものが出ます。

### 3.2 投影画面を開く

司会画面の「投影用リンクを発行」→ そのURLを投影担当へ渡します。
渡された人はログイン無しで同じ画面を開けます。

投影画面を開いたら**画面を一度クリック**してください。
ブラウザの決まりで、操作するまで音が鳴りません。

### 3.3 受付をはじめる

司会画面の大きなボタン「**投票をはじめる**」。

投影画面に二次元コードと「投票 ◯票」が出ます。
1票入るたびに短い音が鳴るので、会場へ「入った」ことが伝わります。

二次元コードは受付中ずっと出したままです。途中から来た人もその場で入れます。

### 3.4 締め切る

司会画面の「**投票を締め切る**」。

**この瞬間の票をすべて数えて固めます。** 以後、票は増えません。
押し間違えたときは「そのほかの操作」から受付へ戻せます（固めた集計は捨てます）。

### 3.5 中身を確かめる・直す

司会画面に全順位の表が出ます。ここで確かめてください。

- **票数を直す** … 紙の投票を足す、明らかな異常値を外す、といったときに。
- **投票の記録から数え直す** … 直しすぎたときの戻し口。投票そのものは消していないので、いつでも戻せます。

> **直すのは票数だけです。点数と順位は票数から計算し直します。**
> 点数を直接いじれるようにすると、票数と食い違ったまま発表されてしまいます。

**直せるのは締切後・発表前だけです。**
会場へ出した数字が後から変わると混乱するためです。

### 3.6 発表する

司会画面の「**結果発表をはじめる**」→「**3位を発表**」「**2位を発表**」…と押していきます。

- 発表は**下の順位から**です。1位から出すと、そのあとを誰も見ません。
- 押すとすぐ答えが出るのではなく、投影画面に「3位は…」と出てためる音が鳴り、
  鳴り終わったところで中身が出ます。
- **1位だけはファンファーレ**が鳴ります。
- 同点は同じ順位で並びます（1位が2つなら次は3位）。

**発表を始めたら受付へは戻せません。** 結果を見てから投票できてしまうためです。

参加者の手元にも、発表済みの順位が同じ順で出ます。
自分が選んだものには「あなたが選んだもの」と付きます。

### 3.7 終わる

「投票を終了」。誤って終了しても「投票を再開」から戻れます（投票と集計は残ります）。

## 4. 効果音

投影画面だけで鳴ります。参加者のスマートフォンからは一切鳴りません。

| 名前            | 鳴るところ                           |
| --------------- | ------------------------------------ |
| `poll-vote`     | 投票が 1 票入った瞬間                |
| `poll-drumroll` | 順位を出すまでの「ため」（繰り返し） |
| `poll-result`   | 2位以下の順位が出た瞬間              |
| `fanfare`       | **1位**が出た瞬間                    |

管理画面 → **効果音** から、デプロイし直さずに差し替えられます。
`poll-vote` は 200 人が一斉に押す場面で鳴るので、**短い素材**にしてください
（長いと重なって鳴りっぱなしになり、会場の話し声を消してしまいます）。

`poll-drumroll` は**長さ 1 秒ちょうど**の素材が向いています。繰り返して鳴らすため、
長さがずれると継ぎ目で拍が崩れます。ためる時間は素材の実際の長さに合わせます
（1.5〜6 秒の範囲に収めます）。

## 5. 気をつけること

### 5.1 投票の秘密

- 誰が何に入れたかは、**本人と司会しか読めません**（Security Rules で塞いでいます）。
- **受付中は票の内訳を誰にも渡しません。** 参加者にも投影にも送っていません。
  途中経過が見えると、あとの人の投票が引っぱられるためです。
  投影に出るのは「何票入ったか」だけです。
- **まだ発表していない順位は、投影画面へも届いていません。**
  画面で隠しているのではないので、投影機の裏側から覗いても先は読めません。

### 5.2 1台1票の仕組み

投票のドキュメント ID を参加者 ID にして書き込みます。
二度目は Firestore が弾くので、同時に 2 回送られても通るのは片方だけです。

同じ端末で二次元コードを読み直しても、同じ参加者として扱われます。
**端末を変えれば別の1票になります。** 厳密な本人確認はしていません
（社内の催しで使う前提です。外部へ公開する投票には向きません）。

### 5.3 練習してから本番へ

司会画面の「入っている票をすべて捨てる」で、練習の票を消してから本番を始められます。
捨てると、同じ端末からもう一度投票できるようになります。

### 5.4 参加人数の上限

ルーム作成時に決めます。1台につき1票なので、そのまま投票できる人数の上限になります。
