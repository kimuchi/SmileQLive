# 抽選会・ビンゴ・ルーレットの進め方 — SmileQ Live

クイズと同じ仕組みの上で、**抽選会**・**ビンゴ**・**ルーレット**を開けます。
どれも「サーバーが 1 つ引いて、投影画面が見せる」進行で、
投影画面と司会画面だけで完結します。
参加者のスマートフォンは使いません（ビンゴのカードは紙で配る前提です）。

---

## 1. どのモードを選ぶか

| モード     | 出てくるもの     | 使う抽選リスト         | 引いたものは                 | 参加者のスマホ |
| ---------- | ---------------- | ---------------------- | ---------------------------- | -------------- |
| クイズ     | 問題             | （クイズを選ぶ）       | —                            | 使う           |
| 抽選会     | 当選者           | 名簿 / 品目            | 母集団から外れる             | 使わない       |
| ビンゴ     | 球               | 数字 / 品目            | 母集団から外れる             | 使わない       |
| ルーレット | 円盤の止まった扇 | 重み付き / 名簿 / 品目 | **外れない（何度でも出る）** | 使わない       |

モードは**ルームを作るときに決め、途中で変えられません**。
クイズのあとに抽選会をやる場合は、抽選会のルームを別に作ります。

> ルーレットだけは引いたものを母集団から外しません。
> 円盤の扇は回すたびに減りませんし、減らすと重みの意味が無くなるからです
> （残り 1 つになれば必ずそれが出てしまいます）。

## 2. 準備 — 抽選リストを作る

管理画面 → **抽選リスト** → 新規作成。

### 2.1 名簿（抽選会）

人の名前・部署名・座席番号など、文字だけの一覧です。

**スプレッドシートから貼り付けられます。**
Google スプレッドシートや Excel で範囲を選んでコピーし、取り込み欄へ貼るだけです。

```
参加者      当選
山田太郎    1
田中花子
佐藤次郎
```

- 「参加者」「氏名」「名前」などの見出し行は自動で見分けて飛ばします
- 「当選」列のような余分な列があっても、名前の列だけを読みます
- 列を選び直すこともできます
- CSV ファイルの読み込みにも対応しています（ファイルはサーバーへ送りません）

取り込んだあとに **何件読めたか・空行を何件飛ばしたか・同じ名前が何件あったか**を
画面に出します。黙って一部を落とすことはありません。

> 同姓同名はそのまま取り込みます。実際にありうるので、勝手に消しません。

### 2.2 数字（ビンゴ）

範囲だけを決めます。既定は **1〜75**（一般的なビンゴ）。
1 件ずつ登録する必要はありません。

### 2.3 品目（文字＋画像）

景品名などの文字と、その写真の組み合わせです。
抽選会（景品の抽選）にもビンゴ（景品ビンゴ）にも使えます。

### 2.4 重み付き（項目名＋重み） — ルーレット用

ルーレットの扇です。**重みが大きいほど扇が広くなり、当たりやすくなります。**

タブ区切り（スプレッドシートからのコピー）でも CSV でも貼り付けられます。

```
項目	重み
大当たり	1
あたり	4
はずれ	15
もう一回	5
```

- 見出し行に「重み」「ウエイト」「確率」「割合」「比率」「weight」などがあれば、その列を重みにします
- 見出しが無くても、**2 列だけで 2 列目が全部数字なら**「項目名＋重み」とみなします
- 迷ったときは読みません。勝手に重みを付けるより、同じ幅で出すほうが驚かせないからです
- 全角数字・小数も受け取り、整数へ丸めます（扇の幅なので小数に意味がありません）
- 0 以下・空・数字でないものは **1** として扱います（0 は「絶対に当たらない扇」になってしまうため）
- 重みは 1〜100000 の整数です
- 自動で選んだ列が違うときは、**「重みとして読む列」**から選び直せます
- 「重みを読まない」を選べば、いつでも全部同じ幅へ戻せます

貼り付けた時点で、**どの列を重みにするか・1 件ずつの重みが何になるか**を下見に出します。
取り込んだあとにも、どの列を読んだか・何件を 1 に直したかを知らせます。

編集画面では、1 件ごとの重みの横に **その扇が出る確率（%）**を出します。
重みは相対値なので、数字だけ見ても当たりやすさが分からないためです。

> 重みを持たない名簿・品目のリストでもルーレットは回せます。
> そのときは**すべての扇が同じ幅**になります。

### 2.5 演出の設定

抽選リストごとに決められます。

| 設定                   | 何が変わるか                                                     | 既定                     |
| ---------------------- | ---------------------------------------------------------------- | ------------------------ |
| 回す速さ               | ルーレットが候補を切り替える間隔                                 | 50ms                     |
| 回す時間               | 回し続ける時間。これを過ぎてから減速して止まる（抽選会・ビンゴ） | 2500ms                   |
| 止まるまでの時間       | **ルーレット**で「ストップ」を押してから実際に止まるまで         | 4000ms                   |
| 結果の文字の大きさ     | 当選者・球の文字の大きさ                                         | 240                      |
| 履歴の文字の大きさ     | 一覧に並べる文字の大きさ                                         | 96                       |
| 投影の見せ方           | 下の 3 通りから選ぶ                                              | 大きい表示と一覧を並べる |
| 背景画像               | 投影の背景に敷く画像                                             | なし                     |
| オープニング動画の URL | 開始前に流す動画                                                 | なし                     |

文字の大きさは **1920×1080 を基準にした数値**です。
実際の投影機の解像度に合わせて自動で比例します。

ルーレットの「止まるまでの時間」は、**司会が押した時点から**数えます。
長くすると、止まる直前の駆け引きを長く見せられます（500〜20000ms）。

#### 投影の見せ方

| 選択                     | 画面                                     | 向いている場面                                                                                           |
| ------------------------ | ---------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| いま出たものを大きく     | 出たものだけを画面いっぱいに             | 1 件ずつ発表して盛り上げたいとき。一覧は「出た球」ボタンで開けます                                       |
| 大きい表示と一覧を並べる | 左に出たもの、右に盤面・一覧             | ビンゴの標準。手元のカードと見比べながら進められます                                                     |
| 出たものの一覧だけ       | これまでに出たものを画面いっぱいに並べる | あとから来た人が追いつけるようにするとき。会場の隅のサブ画面や休憩中の掲示、抽選会の当選者の貼り出しにも |

「出たものの一覧だけ」では、いちばん新しいものだけ色を変えます。
件数に応じて 1 つあたりの大きさが変わるので、10 件でも 75 件でも画面に収まります。

> この設定より前に作った抽選リストは、「既出を常に出す」がオンなら
> 「大きい表示と一覧を並べる」、オフなら「いま出たものを大きく」として読みます。
> 開催中に見え方が勝手に変わることはありません。

> **オープニング動画について**
> このアプリは動画のアップロードを受け付けません（画像だけを許可しています）。
> すでにどこかに置いてある mp4 などの **URL** を指定してください。
> 自動では流れません。投影画面で「オープニングを流す」を押したときだけ再生します。

## 3. 当日の流れ

1. 管理画面 → **ルームを作る** → モードを選ぶ → 抽選リストを選ぶ
2. 司会画面が開く。**投影用リンクを発行**して投影機のブラウザで開く
3. 投影画面は開いた時点で動きます。効果音だけ、鳴らない状態のときは
   画面下の帯が出るので、**画面のどこかをクリック**すれば鳴るようになります
4. 司会画面の「はじめる」を押す
5. あとは **「抽選する」／「1つ引く」を押すだけ**
   （ルーレットは **「スタート」→「ストップ」**の 2 段です）

| 操作                | いつ使うか                                             |
| ------------------- | ------------------------------------------------------ |
| 抽選する / 1つ引く  | ふつうの進行（抽選会・ビンゴ）                         |
| スタート            | ルーレットの円盤を回しはじめる                         |
| ストップ            | ルーレットを止める。**押した瞬間に当たりが決まります** |
| 次へ                | 抽選会・ルーレットで、表示を READY へ戻す              |
| 直前の1件を取り消す | 引き間違い・二度押しからの復帰                         |
| 最初からやり直す    | 全部戻す（GAS 版の「当選リセット」）                   |
| 終了する            | 締めくくり                                             |
| 再開する            | 誤って終了したとき                                     |

### ルーレットの当たりはいつ決まるか

**「ストップ」を押した瞬間**に、サーバーが重みに応じて 1 つ引いて記録します。
投影画面は、決まった扇が真上の針の下へ来る角度を計算して回しているだけです。

つまり「スタート」の時点では**まだ何も決まっていません**。
回っている絵を先に見せてから当たりを選ぶ、ということはしていないので、
司会画面と投影画面が別の端末でも同じ結果になります。

投影画面の右上から、**当選者一覧 / 出た球**をいつでも出せます。
「さっき誰が当たったか」を聞かれたときに、司会が言い直さなくて済みます。

## 4. 効果音

| 音          | 鳴る場面                                                           |
| ----------- | ------------------------------------------------------------------ |
| `draw-spin` | 回している間ずっと（ルーレットは「スタート」から「ストップ」まで） |
| `draw-win`  | 引いたものが確定した瞬間                                           |

同梱の音がそのまま鳴ります。
差し替えるときは **管理画面 → 効果音**（デプロイし直さずに変えられます）。
詳しくは docs/OPERATIONS.md の効果音の節。

## 5. GAS 版の抽選アプリからの移行

| GAS 版                         | SmileQ Live                            |
| ------------------------------ | -------------------------------------- |
| スプレッドシートの「参加者」列 | 抽選リスト（貼り付け／CSV 取り込み）   |
| 「当選」列の 1,2,3…            | 引いた順（そのまま当選順位になります） |
| メニューの「当選リセット」     | 「最初からやり直す」                   |
| `ROULETTE_SPEED`               | 回す速さ                               |
| `LOTTERY_FONT_SIZE`            | 結果の文字の大きさ                     |
| `HISTORY_FONT_SIZE`            | 履歴の文字の大きさ                     |
| `IMAGE_FILE_ID`（背景画像）    | 背景画像（管理画面からアップロード）   |
| `SOUND_FILE_ID`（当選音）      | 効果音 `draw-win`                      |
| `OPENING_VIDEO_ID`（動画）     | オープニング動画の URL                 |
| HISTORY ボタン                 | 投影画面の「当選者一覧」               |
| 全画面ボタン                   | 投影画面が元から持っています           |

### 変わったこと

- **当たりを決めるのはサーバー**になりました。
  GAS 版はブラウザの中で当選者を選んでいましたが、
  こちらは「引く」操作を受けたサーバーがその瞬間に決めて記録します。
  投影画面はそれを受け取ってルーレットを見せるだけです。
  司会画面と投影画面が別々の端末でも、同じ結果を見られます。
- 選び方に**偏りの無い乱数**を使っています。
- **二度押ししても 1 回しか進みません**（状態番号の検証）。
- 引いた記録は Firestore に残るため、**ブラウザを閉じても続きから再開できます**。

## 6. 困ったとき

| 症状                       | 見るところ                                                                                          |
| -------------------------- | --------------------------------------------------------------------------------------------------- |
| 投影画面に何も出ない       | 投影用リンクの期限。司会画面から発行し直す                                                          |
| 音が鳴らない               | 投影画面のどこかをクリックする。素材の確認は `npm run sounds:check`                                 |
| 景品の写真を入れられない   | `npm run media:doctor -- --file <失敗した画像>` で原因が出ます                                      |
| ルーレットが回らない       | 候補が 1 件のときは回しません（そのまま出ます）                                                     |
| 重みを貼ったのに扇が同じ幅 | リストの種類が「重み付き」か確認する。名簿・品目では重みを読みません                                |
| 扇に文字が出ない           | 細すぎる扇には入れません（読めないうえ隣と重なるため）。色と結果の表示で伝わります                  |
| 同じ項目が何度も出る       | ルーレットは引いたものを外しません。1 回ずつにしたいなら抽選会モードを使う                          |
| 引けなくなった             | 全部引き切ると「終了」へ導きます。続けるなら「最初からやり直す」                                    |
| 名簿が取り込めない         | 見出し行の扱い・列の指定を確認する。取り込み前に下見が出ます                                        |
| 抽選リストを選べない       | モードに合う種類だけが選べます（抽選会=名簿/品目、ビンゴ=数字/品目、ルーレット=重み付き/名簿/品目） |
